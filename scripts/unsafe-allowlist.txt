# quench-ui forbids unsafe code outright; the scan lists the file because it treats the lint switch as a use.
./quench-ui/src/lib.rs
# The wasm boundary. Buffers are `Vec`s kept by address and imports are `safe fn`s, so no unsafe block, unsafe fn or
# raw pointer is left: what remains is the `#[unsafe(no_mangle)]` that makes a function an export (ffi.rs) and the
# `unsafe extern` block that declares the imports (host/wasm.rs). Neither can be written without the keyword.
./quench-ui-web/src/ffi.rs
./quench-ui-web/src/host/wasm.rs
# The Linux desktop host's calls into GTK 3, webkit2gtk and GLib (a C API: there is no safe way to call it, and a process
# boundary would only move the same calls). Every unsafe of the crate is in this one file, behind safe `!Send` types with
# the contract written at the top of it and in docs/quench-desktop.md; the window tests exercise each call.
./quench-desktop/src/ffi.rs
# The native renderer's Wayland client: file descriptors over the compositor's socket (`sendmsg`/`recvmsg` with
# `SCM_RIGHTS`) and shared memory (`memfd_create`, `mmap`), none of which the standard library offers. Every unsafe of
# the crate is in this one file, with the contract at the top and a test for each call; docs/quench-desktop-wayland.md.
./quench-desktop-wayland/src/sys.rs
