## Design

Every builder stores plain owned fields (`String`, `Option<String>`, `bool`, `Option<Element>`) and assembles `Element`s from `quench-web` in `build`. There is no I/O, no global state and no `unsafe`; all builders are `Clone + Debug + Default` and `Send + Sync`. Because `build` consumes the builder, build once per element.

All text goes through `Element::text` / `Element::attr`, so it is HTML-escaped; none of the builders calls `.raw()`.

`Default` is derived on every builder, but `ButtonBuilder::new`, `FormInput::new` set non-default initial values (`button_type = "button"`, `input_type = "text"`). `ButtonBuilder::default()` and `FormInput::default()` start with an empty `type`, which renders `type=""`.

## CSS classes emitted

| Builder | Classes |
|---|---|
| `ButtonBuilder` | `btn`, or the variant's `btn btn-primary` / `btn-secondary` / `btn-danger` / `btn-success` / `btn-warning` / `btn-outline` |
| `Card` | `card`, `card-compact`, `card-header`, `card-body`, `card-footer` |
| `Panel` | `panel`, `panel-bordered`, `panel-highlighted`, `panel-header`, `panel-content` |
| `Container` | `container`, `container-fluid`, `container-centered` |
| `empty_state` | `empty` |
| forms | `form-group` |
| `StatusBadge` | `status-badge`, `status-info` / `-success` / `-warning` / `-error`; icon classes `fas fa-info-circle` etc. |
| `AlertBox` | `alert`, `alert-status-info` / `-success` / `-warning` / `-error`, `alert-close`; icon `fas fa-times` |

Which of these the shared stylesheet defines: the base CSS written by `quench-web` (`dist/assets/css/style.css`, generated by `quench-style`) contains `.empty` but **no rule for `btn`, `card`, `panel`, `container*`, `form-group`, `status-*` or `alert*`** (checked against the generated `quench-web/dist/assets/css/style.css`). Those widgets therefore render unstyled unless the service ships CSS for them. The icon classes need Font Awesome, which the shell loads from a CDN.

## Output stability

`Element` renders attributes sorted by name, so rendered strings are stable; the examples in these pages are exact.
