# Quench Http

A lightweight, `poem`-shaped HTTP framework — routing (including regex-style multi-segment wildcard path segments), annotation-discovered routes and components (`#[get]`/`#[injectable]`, no manual registration), a real dependency-injection graph, and plain-async middleware, instead of `actix-web`'s `Service`/`Transform` boilerplate.

See [docs/crates/quench-http](../docs/crates/quench-http/index.md) for the full integrator guide.
