# Quench Http

A lightweight, `poem`-shaped HTTP framework — routing (including actix-router's regex-constrained wildcard path segments), annotation-discovered routes and components (`#[get]`/`#[injectable]`, no manual registration), a real dependency-injection graph, and plain-async middleware, instead of `actix-web`'s `Service`/`Transform` boilerplate.

See [docs/quench-http.md](../docs/quench-http.md) for the full integrator guide.
