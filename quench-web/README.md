# Quench Web

Library-only, dependency-light HTML/CSS/JS builder used to assemble server-rendered UI pages without a templating engine — chainable `Element`/`PageBuilder` builders, page/shell/theme/i18n helpers, and a shared `q-shell-*` class vocabulary so every service's UI looks and behaves consistently.

See [docs/crates/quench-web/index.md](../docs/crates/quench-web/index.md) for full documentation.
